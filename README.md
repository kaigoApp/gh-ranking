# ジモふく

地元の障害福祉が見つかるサイトです。全国の障害福祉サービス事業所を、目的（暮らす場所・働く・子どもの支援など）と地域からさがせます。
事業所の数と推移も、サービス別・都道府県別・市区町村別に見られます。
国（WAM NET）のオープンデータを自動で取得して、ページを作り直します。

公開ページ：https://jimofuku.jp/

## ページの構成

| URL | 内容 |
| --- | --- |
| `/` | 検索、目的からさがす、最近できたグループホーム、地域からさがす、全国の推移 |
| `/s/<サービス>/` | サービス別ランキング（都道府県・市区町村・運営法人・新規掲載・掲載終了） |
| `/p/<都道府県>/` | 都道府県のサービス別・市区町村別の事業所数 |
| `/p/<都道府県>/<市区町村>/` | 市区町村の事業所の一覧と、サービス別の事業所数 |
| `/p/<都道府県>/<市区町村>/<サービス>/` | 市区町村 × サービスの事業所の一覧（「札幌市中央区の就労継続支援B型」など） |
| `/f/<事業所番号>/` | 事業所ページ（全サービス。電話・地図・行っているサービス・同じ法人や地域の事業所） |
| `/data/` | お仕事で使う方へ：地域のくらべ表（人口1万人あたりつき）、半年の動き、そのサービスがない市区町村、CSV ダウンロード |
| `/data/<都道府県>/<市区町村>/` | 市区町村のまとめ（印刷用）：サービス別の数・増減・県内順位・人口あたり、主な運営法人、半年の動き |
| `/data/near/` | 住所・市区町村・現在地から、近い事業所を近い順に出す |
| `/report/` | レポート：データの時点ごとに1本（全国の推移、サービス別、地域の差、入れ替わり、運営法人の種類、サービスがない市区町村）。データが増えると自動で1本増える |
| `/c/<法人番号>/` | 法人ページ（3事業所以上を運営する法人）：サービス・都道府県・事業所の一覧 |
| `/privacy/` | プライバシーとアクセス解析（Google アナリティクス）について |

## アクセス解析

`scripts/build.py` の `GA_ID` に Google アナリティクスの測定 ID を入れると、全ページにタグが入ります。空にすると外れます。

## 仕組み

1. `scripts/fetch.py` が WAM NET の公開ページを見て、まだ持っていない時点・サービスの ZIP を取得し、
   必要な列だけを抜き出した gzip CSV（`data/slim/<サービスコード>/<YYYYMM>.csv.gz`）にして保存します。
2. `scripts/build.py` が `data/slim/` の全時点を集計し、`public/` にサイト一式を書き出します。
   デザインは `site/assets/`（CSS と、サービス別ページのランキング用 JS）にあります。
   LINE や X で送ったときのシェア用画像（`public/og/`）は `scripts/ogp.py` が作ります。Pillow と `.fonts/` のフォントが無ければ作らずに進みます。
   人口あたりの数には `data/pop.csv`（`scripts/fetch_pop.py` が総務省の住民基本台帳人口から作る）を使います。新しい年のファイルが出たら、`fetch_pop.py` の URL と時点を書きかえます。
3. GitHub Actions（`.github/workflows/build.yml`）が、毎月1日と15日、または main への push のたびに 1→2 を実行し、
   エックスサーバー（jimofuku.jp）に公開します。

就労継続支援B型の平均工賃（月額）は WAM NET のデータに無いので、都道府県が毎年出す「工賃実績」の一覧から取ります。
`data/kouchin/urls.txt` に県ごとの資料の URL を書くと、Actions（`.github/workflows/kouchin.yml`）が取りに行き、
`scripts/parse_kouchin.py` が事業所名・法人名・市区町村で事業所番号に結びつけて `data/kouchin/kouchin.csv` を作ります。
新しい年度の資料が出たら URL を書きかえ、資料の形が変わったら `parse_kouchin.py` の `SOURCES`（列の位置）を直します。

WAM NET のデータは毎年3月末時点と9月末時点の年2回公開されます。
サービスの名前と URL に使う名前は `scripts/services.py` で決めています。

## 手元で作るとき

```
python scripts/fetch.py
SITE_URL=https://kaigoapp.github.io/gh-ranking python scripts/build.py
```

Python 3.10 以上の標準ライブラリだけで動きます。自動取得がうまくいかない場合は、
WAM NET からダウンロードした ZIP を `python scripts/fetch.py --zip sfkopendata_202603_33.zip` のように取り込めます。
